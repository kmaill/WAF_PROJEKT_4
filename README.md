# WAF_PROJEKT_4

## Opis
Zestaw skryptów pod bezpieczną konfigurację środowiska pracy na Ubuntu Server 26.04.1 LTS.

## Rzeczy potrzebne do projektu
- Obraz ISO Ubuntu Server 26.04.1 LTS ze strony https://ubuntu.com/download/server
- Cokolwiek do tworzenia maszyn wirtualnych, np. Oracle VirtualBox na Windows

## Uruchamiania skryptów
Po sklonowaniu trzeba nadać uprawnienia plikom, np.:
```bash
chmod +x ufw.sh
```

Następnie normalnie uruchomić:
```bash
sudo ./ufw.sh
```
